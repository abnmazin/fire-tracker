# Fire Tracker

Installable PWA for managing fire extinguishers (inspection tracking, maintenance schedules, hierarchical locations, users, reports) with full offline support.

## Quick start

```bash
npm install      # install dependencies
npm run dev      # development server
npm run build    # production build
```
